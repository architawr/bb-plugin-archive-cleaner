Run bb archive-cleaner preview for selected projects and bb archive-cleaner status for policy and the latest daily run. In Archived Threads Cleaner settings select projects by name or select all existing projects, and separately choose whether to include future projects, then save the selection. Configure retention days and automatic cleanup separately. While enabled, the worker checks on startup and once per minute. Cleanup is due 24 hours after the previous successful pass. One overdue pass covers any downtime. Failed passes retry after five minutes. Parents with dependents are reconsidered the next day. Deletion requests use BB lifecycle cleanup. Storage and environment completion require separate verification. Project attachments may survive deletion.
